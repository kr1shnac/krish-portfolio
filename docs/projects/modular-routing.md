# Modular Routing

**Type:** In-Progress / Research
**Subtitle:** Cost-Aware LLM Model Selection

## Description
A complexity-aware router that directs simple queries to cheap, fast models and complex ones to powerful models automatically — targeting the inference-cost problem behind Uber's 2025 rollback of internal AI tooling access.

## Highlights
- Query Complexity Analysis
- Multi-Model Routing
- Cost Optimization
- Heuristic Tuning

## Tech Stack
Python, OpenRouter API, Heuristics
